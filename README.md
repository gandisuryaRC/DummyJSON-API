# Tugas Pemrograman Web - CRUD REST API (SPA)

Repository ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Web. Aplikasi ini berbentuk Single Page Application (SPA) yang mensimulasikan proses CRUD (Create, Read, Update, Delete) menggunakan Vanilla JavaScript (tanpa framework) dan Fetch API yang terhubung ke layanan DummyJSON.


### Cara 1: Buka Langsung (Paling Mudah)
1. Clone atau download repository ini ke komputer kamu.
2. Masuk ke foldernya, lalu klik dua kali pada file `index.html`.
3. Aplikasi akan langsung terbuka di browser.
